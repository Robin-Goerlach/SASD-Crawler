# Glossar

| Begriff | Bedeutung |
|---|---|
| Crawler | Komponente, die Quellen systematisch entdeckt und aktualisiert |
| Discovery | Feststellen, welche Objekte in einer Quelle vorhanden sind |
| Reconciliation | Abgleich zwischen neuem Scan und bekanntem Dokumentregister |
| Full Scan | vollständige Traversierung einer Quelle |
| ScanRunId | Identität eines vollständigen Scanlaufs |
| Source | konfigurierte Datenquelle |
| Media | entfernbarer Datenträger als stabiles Domänenobjekt |
| MediaId | interne stabile Identität eines Mediums |
| Document Registry | führender Metadatenzustand bekannter Dokumente |
| Search Index | rekonstruierbarer Volltextindex |
| Extraction | Text-/Metadatengewinnung aus Dokumenten |
| OCR | Zeichenerkennung aus Bild-/Scaninhalten |
| Extraction Cache | rekonstruierbarer Zwischenspeicher extrahierter Texte |
| WorkItem | dauerhafte Arbeitseinheit der Processing Queue |
| Lease | zeitlich begrenzte Reservierung eines WorkItems durch einen Worker |
| Last Known Good | zuletzt erfolgreich indexierte Revision, die bei neuem Parserfehler erhalten bleiben kann |
| Golden Corpus | versionierter Dokumenttestbestand |
| Golden Query Set | versionierte Abfragen mit erwarteten Treffern |
| Gate | formale Freigabebedingung zwischen Meilensteinen |
| Evidence | Nachweisdateien zu Build, Tests, Performance, Security oder Migration |
| ADR | Architecture Decision Record |
| Change Request | kontrollierter Änderungsantrag mit Auswirkungsanalyse |
| MVP | erste fachlich vollständige Kernversion, geplant als 0.5.0 |
| Shared Mode | späterer zentraler Mehrbenutzerbetrieb |
